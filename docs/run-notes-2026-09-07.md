## 1. Slogan follows the cursor (`assets/js/slogan.js`, new)

The old effect was a CSS keyframe wave: hovering anywhere on the line started one canned
pass at 52ms per letter, always left to right, regardless of where the pointer was.

Now every one of the 20 glyphs is a damped spring driven by its distance to the cursor.
Target lift = 13px x smoothstep(1 - d/150px), with vertical distance weighted 0.55 so the
crest is wide horizontally and tight vertically. Spring k=0.24, damping 0.74 per frame, so
the wave lags the pointer slightly and overshoots on the way back. Glow tracks the same
value. The loop stops itself 8 frames after everything has settled.

Full stops are separate: 26px of lift, and crossing one adds a discrete velocity kick of
-1.15, so it hops rather than swelling. Measured on the live site, sweeping the cursor
across the line: dot 1 reaches -27.4px, and with the cursor parked on the "u" of Simulate
the letter lifts are `0 0 0 0 -1 -3.7 -8.1 -11.9 -10.3 -6.8 -3.4 -0.2 0 ...`, i.e. the
crest is under the pointer and dies out four letters away.

Only on `(hover:hover) and (pointer:fine)`. Touch keeps the old CSS wave, and
`prefers-reduced-motion` gets nothing. The JS adds `body.slogan-js`, which switches the
CSS animation off so the two never fight.

The canvas has to be wider than the drawn cradle because a ball at full lift swings
84*sin(1.05)=72.8px sideways, so the art was floating 174px past the end of the slogan
even though the canvas box started 43px after it.

- Desktop: hero gap 46 -> 18px max, canvas 392 -> 330px, `margin-left:-52px`, and the art
  is anchored inside the canvas by a new `--cradle-shift` custom property (-42) rather
  than centred. Bar left edge is now **865px** with the slogan ending at 814.6 — 50px, was 174.
- Portrait phone: `cradle.js` now measures the last word of the slogan and drops the bar
  into the empty space beside it. Bar centre y = centre of the "Learn." line, bar left =
  word right + 20px, clamped to the canvas. Measured: 320px screen bar at (136,144) vs
  "Learn." ending at (122,144); 390 -> (165,157) vs 144; 414 -> (174,162) vs 154.
  Right-hand swing clearance drops from 85 to 40px on phones only, which is what makes
  320px fit; a ball only reaches it at full manual lift.
- The placement is re-measured after the intro animation ends, on `fonts.ready`, on
  resize and on orientationchange. Without that it was 17px low, because the words start
  0.36em below their final position.

## 5. Turing patterns — full integration

original is kept at `docs/originals/turing-patterns.html`; it is no longer served as a
loose page at the site root.

**Physics and shaders untouched.** Every change is chrome, layout or control ordering.

- **Head block is now byte-identical to the gravity sim's** (tokens, fonts, full-bleed

  parameter map, the toggles and the WebGL notice. Serif headings, the four-colour

- **Card glyph:** five wavy stripes that stretch outward while four fainter ones fade in
