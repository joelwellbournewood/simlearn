# SimWorld assets

## Rules
1. **Provenance or it does not ship.** Every file gets a row in the table below: what it is,
   where it came from, its licence, and who made it. An asset with an unknown source is
   deleted rather than risked, because a paid desktop build is on the table.
2. **Source files live here, built files do not.** Anything generated by `tools/` is written
   to `build/` and is not committed.
3. **Data before code.** Tuning numbers belong in `data/`, never in a source file.
4. **Keep it small.** Nothing over 1 MB without a note saying why. This repository also
   serves a website.

## Folders
| Folder | Holds | Formats |
|---|---|---|
| `palettes/` | colour ramps for creatures, terrain, and field overlays | JSON, 8 to 16 stops |
| `sprites/` | body parts, terrain tiles, particles, icons | SVG where possible, PNG at 2x otherwise |
| `audio/` | ambience loops, event stings | OGG plus M4A fallback, mono, 48 kHz |
| `fonts/` | only a font the site does not already load | WOFF2 |
| `data/` | balance tables, scenario definitions, math tables | JSON, hand editable, commented via a `_note` key |
| `ref/` | reference photographs, sketches, screenshots, notes | never shipped, never loaded at runtime |

## Naming
`category-name-variant.ext`, lower case, hyphens only. Example:
`sprites/body-segment-armoured-2x.png`, `palettes/diet-bands.json`,
`data/balance.json`, `data/scenario-lean-season.json`.

## Colour
Creature and terrain colour is generated from the palettes here, and the chrome (panel,
lines, text, accents) comes from the site's own tokens so SimWorld matches SimLearn. The
fixed meaning of every channel is in `../docs/07-READABILITY.md` and may not be changed for
aesthetic reasons.
