Schelling's Segregation Model

Two groups of agents on a grid. Each just wants a fraction of neighbors like itself — a mild preference, not hostility. Yet the whole grid ends up sharply segregated. No agent aims for that outcome. Thomas Schelling, 1971.

Unhappy agents: 0%
Segregation index: 0%

Click an occupied cell to uproot that agent to a random empty spot. Click an empty cell to drop a new agent (random group) there. Watch the segregation index react.

Segregation index = average share of same-group neighbors across all agents. ~50% ≈ well-mixed by chance; >70% = sharply segregated.
